🤖 AGENT WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. PLANNER AGENT
   Input:  Goal + Inventory Summary
   Output: Execution Plan (JSON)
   Role:   Strategic planning and goal understanding

2. INVENTORY AGENT
   Input:  All inventory data
   Output: Materials below 25% threshold (JSON)
   Rule:   stock_percentage < 25% triggers procurement

3. PROCUREMENT AGENT
   Input:  Materials needing reorder
   Output: Recommended order quantities (JSON)
   Logic:  Calculate gap to max capacity

4. VENDOR ANALYSIS AGENT
   Input:  Available vendors for material
   Output: Vendor evaluations (JSON)
   Criteria: Price, Lead Time, Reliability

5. COST OPTIMIZATION AGENT
   Input:  Vendor evaluations + Order quantity
   Output: Selected vendor + Scoring (JSON)
   Formula:
     • Price Score (40%): best_price / vendor_price * 100
     • Lead Time Score (30%): min_lead_time / vendor_lead_time * 100
     • Reliability Score (30%): vendor_reliability_score
     • Final = (price × 0.40) + (lead_time × 0.30) + (reliability × 0.30)

6. COORDINATOR AGENT
   Input:  All previous outputs
   Output: Final validated decision (JSON)
   Role:   Validation, consistency check, final synthesis
